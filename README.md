# Точка сохранения

**Личный трекер-игра для айфона и андроида.** Маленькие квесты каждый день, случайная карта дня, вызов недели и честная оценка недели из 100. Привычки, которые держатся, со временем уходят на автопилот.

## Установка за минуту

1. Открой ссылку на приложение в **Safari** (на андроиде — в Chrome).
2. Нажми **«Поделиться» → «На экран "Домой"»** (на андроиде: меню ⋮ → «Добавить на главный экран»).
3. Один раз запусти приложение с иконки при интернете. Дальше оно работает **без сети**.

Регистрация не нужна, сервера нет, платить нечего.

## Правила честной игры

Приложение сделано для тех, кто не доверяет себе. Накликать прогресс неудобно и заметно:

- **Окна отметок.** Подъём — до 14:00, душ — 2 часа после подъёма, вечерние квесты — только вечером. Задним числом нельзя.
- **Одно исправление в неделю**, если реально забыл нажать вчера. Засчитывается вполсилы и без монет.
- **Фото только с камеры** для части квестов и карт. Без фото — половина опыта и ноль монет.
- **Таймеры** для прогулки, чтения, учёбы. «Финиш» не сработает раньше времени.
- **Детектор спринт-кликера.** Три отметки меньше чем за минуту — приложение спросит, всё ли честно. Две такие ситуации за неделю — неделя получает ⚠, ачивки замораживаются, а на карточке для друзей это видно вместе со строкой «проверено X из Y».

А чтобы срыв не убивал мотивацию:

- **Два щита в неделю** закрывают пропуск без штрафа.
- **Серия не обнуляется**: без щитов она падает наполовину.
- **Кнопка «Не ложился спать»** записывает ночь и причину без наказания, чтобы потом увидеть закономерность в отчёте.
- **День заканчивается в 04:00**: если лёг в 2 ночи, отбой засчитается во вчерашний день.

## Приватность

- Все записи хранятся **только в памяти телефона** (localStorage и IndexedDB браузера).
- На GitHub лежит **только код** приложения. Кто угодно может открыть ссылку и увидит **пустое** приложение со своими данными, а не твоими.
- Приложение не отправляет данные никуда: нет сервера, аналитики и аккаунтов.
- Фото-подтверждения хранятся 2 недели и удаляются автоматически.

> **Важно:** удалишь иконку или очистишь данные Safari — прогресс пропадёт. Раз в неделю делай **Профиль → Сохранить копию** и отправляй её себе в «Избранное».

## Обновления

Приложение обновляется само. Когда выходит новая версия, при следующем запуске с интернетом оно подтянет её, перезагрузится и покажет окно **«Что нового»** со списком добавленного и исправленного. Серия, опыт, записи и настройки сохраняются.

## FAQ

<details>
<summary><b>Почему нет push-уведомлений?</b></summary>

Для пушей на айфоне нужен сервер, а приложение специально без него. Напоминания ставятся через Календарь: вкладка «Квесты» → время у квеста → «В Календарь».
</details>

<details>
<summary><b>Можно перенести прогресс на новый телефон?</b></summary>

Да. Старый телефон: Профиль → Сохранить копию. Новый: установи приложение → Профиль → Восстановить → вставь копию. Фото не переносятся.
</details>

<details>
<summary><b>Можно поменять квесты, карты или ачивки под себя?</b></summary>

Да, весь контент лежит в одном файле [`data.js`](data.js). Свои сайд-квесты и награды можно добавить прямо в приложении.
</details>

## Для разработчика

Чистые HTML, CSS и JavaScript без сборки и зависимостей. Хостинг — GitHub Pages.

```
index.html            точка входа
app.js                логика и экраны
data.js               контент: квесты, колода карт, вызовы, ачивки, версия и список изменений
app.css               стили, светлая и тёмная тема
sw.js                 офлайн-кэш (service worker)
manifest.webmanifest  установка на экран «Домой»
```

**Как выпустить новую версию:**
1. Подними `APP_VERSION` в `data.js` и добавь запись в начало `CHANGELOG`.
2. Подними `VERSION` в `sw.js`, иначе телефоны продолжат брать старые файлы из кэша.
3. Закоммить в `main`. GitHub Pages обновится за 1–2 минуты.

Локально: `python3 -m http.server` в папке проекта и открыть `http://localhost:8000`.
